01

MNance

App de finanças pessoais que responde a uma pergunta: no ritmo atual, em quantos anos eu chego na minha meta?

A personal finance app that answers one question: at my current pace, how many years until I reach my goal?

  • React 19
  • TypeScript
  • Firebase
  • Tailwind CSS
  • PWA
  • Vitest
No ar · set–nov/2026Live · Sep–Nov 2026 Abrir o appOpen the app ↗ Código no GitHubCode on GitHub ↗

ProblemaProblem

Eu controlava minhas finanças numa planilha de Excel. Ela mostrava para onde o dinheiro foi, mas não para onde ele estava me levando.

I tracked my finances in an Excel spreadsheet. It showed where the money went, but not where it was taking me.

O que construíWhat I built

Um PWA com o Radar de Patrimônio (tempo até a meta em cenários conservador, base e otimista, com alavancas como aumentar o aporte), carteira e histórico do patrimônio, distribuição da renda por modelo de alocação com reserva de emergência e check-in mensal dos investimentos.

A PWA with a Wealth Radar (time to goal under conservative, base and optimistic scenarios, with levers such as raising contributions), portfolio and net-worth history, income split by allocation model with an emergency fund, and a monthly investment check-in.

DecisõesDecisions

  1. O motor de cálculo (src/core) é TypeScript puro, sem React nem Firebase: testável isolado e pronto para ir para um backend.
  2. Um único motor de projeção alimenta prazo, gráfico, cenários e alavancas. Os números nunca se contradizem.
  3. Meta inatingível vira convite à ação (ajustar aporte, prazo ou meta), não veredito.
  1. The calculation engine (src/core) is pure TypeScript, with no React or Firebase: testable in isolation and ready to move to a backend.
  2. One projection engine feeds the timeline, chart, scenarios and levers. The numbers never contradict each other.
  3. An unreachable goal becomes an invitation to act (adjust contribution, deadline or goal), not a verdict.

ProvaProof

401 testes automatizados passando, incluindo um teste "golden" de precisão com tolerância de ±2%, a métrica de sucesso definida no PRD. Regras do Firestore: só o dono lê e escreve os próprios dados. ~13,9 mil linhas de TypeScript estrito.

401 automated tests passing, including a "golden" precision test with ±2% tolerance, the success metric set in the PRD. Firestore rules: only the owner reads and writes their own data. ~13.9k lines of strict TypeScript.

LimitesLimits

MVP sem backend próprio: os cálculos rodam no navegador e os dados ficam no Firestore. Para usar, é preciso criar uma conta.

An MVP with no backend of its own: calculations run in the browser and data lives in Firestore. Using it requires an account.

Como usei a IAHow I used AI

O Claude Code escreveu a maior parte do código sob minha direção. Eu escrevi o PRD (documento de requisitos), defini as regras de negócio, aprovei cada plano antes da implementação e uso o teste de precisão como critério de aceite.

Claude Code wrote most of the code under my direction. I wrote the PRD (requirements document), defined the business rules, approved every plan before implementation and use the precision test as the acceptance criterion.

02

Agente Financeiro IAAI Finance Agent

Meu primeiro app com IA generativa: diagnóstico financeiro e plano de reserva de emergência, com recomendações do Gemini.

My first generative-AI app: a financial check-up and an emergency-fund plan, with recommendations from Gemini.

  • Python
  • Gemini API
  • Google Sheets API
  • Streamlit
Protótipo de estudo · mai/2025Study prototype · May 2025 Código no GitHubCode on GitHub ↗

ProblemaProblem

Entender o próprio fluxo de caixa e montar uma reserva de emergência, sem precisar de uma planilha complexa.

Understanding your own cash flow and building an emergency fund, without a complex spreadsheet.

O que fazWhat it does

Lê renda, gastos e dívidas; classifica o fluxo de caixa (superavitário, equilibrado ou deficitário); calcula a reserva ideal e uma meta mensal. O Gemini gera as recomendações e tudo vai para um painel no Google Sheets.

Reads income, expenses and debts; classifies cash flow (surplus, balanced or deficit); calculates the ideal emergency fund and a monthly target. Gemini writes the recommendations and everything lands in a Google Sheets dashboard.

DecisãoDecision

Quando a interface web travou (túnel ngrok no Google Colab), priorizei entregar o núcleo funcionando e deixei a interface para depois.

When the web interface got stuck (an ngrok tunnel on Google Colab), I shipped the working core first and left the interface for later.

Como usei a IAHow I used AI

Criei durante uma imersão de IA, quando eu ainda não programava. Todo o código foi feito com IA generativa.

I built it during an AI immersion course, before I could code. All of the code was written with generative AI.

LimitesLimits

É um protótipo de estudo. O app publicado no Streamlit hoje pede login, por isso o link aqui leva ao código.

It's a study prototype. The app hosted on Streamlit currently asks for a login, so the link here goes to the code.

O que mostraWhat it shows

A primeira repetição do meu padrão: ver um problema, construir a ferramenta e aprender no caminho. O MNance é a versão madura disso.

The first rep of my pattern: spot a problem, build the tool, learn along the way. MNance is the mature version of it.

The same method in my day-to-day BI work and in my own projects.

    A dashboard, an automated report by region or, when it's missing, the tool itself.
